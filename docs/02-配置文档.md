# 配置文档：AmpMySQL RPC 服务

> 版本：v1.0 ｜ 状态：阶段 0 交付物

## 1. 配置来源与优先级

`config.php` 为基准配置，支持环境变量覆盖（部署友好），优先级：

```
环境变量 > config.php
```

## 2. 配置项清单

```php
return [
    // RPC 服务监听地址
    'listen' => 'tcp://0.0.0.0:9501',

    'mysql' => [
        'host'            => '127.0.0.1',   // 环境变量 MYSQL_HOST
        'port'            => 3306,          // 环境变量 MYSQL_PORT
        'user'            => 'root',        // 环境变量 MYSQL_USER
        'password'        => '',            // 环境变量 MYSQL_PASSWORD
        'database'        => 'test',        // 环境变量 MYSQL_DATABASE
        'charset'         => 'utf8mb4',
        'max_connections' => 16,            // 环境变量 MYSQL_MAX_CONNECTIONS，连接池上限
        'idle_timeout'    => 60,            // 空闲连接回收秒数
    ],

    'limits' => [
        'sql_timeout'       => 2.0,   // 单条 SQL 执行超时（秒）
        'max_concurrency'   => 64,    // 并发 SQL 上限（限流，保护 MySQL）
        'queue_timeout'     => 0.5,   // 获取并发槽位排队超时（秒），超时返回 -32002
        'read_retry'        => 1,     // 只读 SQL 瞬态错误重试次数
        'slow_sql_ms'       => 500,   // 慢 SQL 日志阈值（毫秒）
    ],

    'log' => [
        'file'         => 'logs/rpc.log',   // 空则只输出 stderr
        'level'        => 'info',
        'max_line_len' => 2048,             // 单条日志截断长度
    ],
];
```

## 3. 参数联动关系

| 配置 | 约束 |
| ---- | ---- |
| `max_connections` | ≤ MySQL 服务端 `max_connections` × 0.8 ÷ RPC 实例数（单实例上限） |
| `max_concurrency` | ≥ `max_connections`（允许少量排队），但不宜过大导致大量排队超时 |
| `sql_timeout` | 必须 < Webman RPC 总超时（3s），建议留 1s 网络余量 |
| `queue_timeout` | 建议 `rpc 总超时 - sql_timeout` 的 1/4 |

## 4. 数据库账号权限

RPC 服务使用的 MySQL 账号按最小权限原则：

- 只授权业务库 `SELECT / INSERT / UPDATE / DELETE`；
- 不授予 `DROP / ALTER / CREATE / FILE / GRANT`；
- 禁止使用 root / super 权限账号。

## 5. 端口与网络

- RPC 端口 9501 仅内网可达，生产环境通过安全组 / 防火墙限制来源 IP；
- docker-compose / k8s 部署时使用服务名互访：`tcp://mysql-rpc:9501`。

## 6. Webman 网关配置（webman-gateway/config/rpc.php）

```php
return [
    'timeout' => 3.0,                          // RPC 总超时（秒），必须 > sql_timeout(2s)
    'address' => getenv('RPC_ADDRESS') ?: 'tcp://127.0.0.1:9501',
    'pool_size' => 4,                          // 每 worker 进程的 RPC 连接数
    'context' => [],                           // TCP 上下文（SSL 等）
    'reconnect_min' => 0.2,                    // 断线重连指数退避下限（秒）
    'reconnect_max' => 5.0,                    // 上限（秒）
    'breaker' => [                             // 简易熔断（滑动窗口）
        'window'       => 20,                  // 统计窗口请求数
        'fail_rate'    => 0.5,                 // 失败率阈值
        'cooldown'     => 5.0,                 // 熔断冷却期（秒）
        'half_open_ok' => 3,                   // 半开态连续成功次数后闭合
    ],
    'enable' => (bool) (getenv('RPC_ENABLE') ?: true),   // 回滚开关：false → 同步 PDO
];
```

环境变量（详见 `webman-gateway/.env.example`）：

| 变量 | 作用 | 默认 |
| ---- | ---- | ---- |
| `RPC_ADDRESS` | RPC 服务地址 | `tcp://127.0.0.1:9501` |
| `RPC_ENABLE` | 回滚开关（0 = 同步 PDO 降级） | `1` |
| `MYSQL_HOST/PORT/USER/PASSWORD/DATABASE` | PDO 降级模式直连配置 | 本机默认值 |

其它网关关键配置：

| 文件 | 配置项 | 说明 |
| ---- | ---- | ---- |
| `config/server.php` | `event_loop => \Workerman\Events\Fiber::class` | **必须**：Revolt 协程循环（纯 PHP，无 Swoole 依赖），`wait()` 挂起依赖它 |
| `config/process.php` | `count => cpu_count() * 4` | worker 进程数；每 worker 各持 `pool_size` 条 RPC 连接 |
| `config/bootstrap.php` | `RpcPoolWarmup` | worker 启动预热连接池，消除首请求冷启动 |

## 7. 超时分级总览（必读）

```
网关 RPC 总超时(3s) > RPC 服务 sql_timeout(2s) > 并发槽排队 queue_timeout(0.5s)
```

- 网关 3s 兜底保证任何情况下 HTTP 请求不悬挂（Timer 清理 pending，防 fd 泄漏）；
- 服务端 2s SQL 超时返回 `-32001`，网关映射为 HTTP 504；
- 排队超时 `-32002` / MySQL 不可达 `-32003` 映射为 HTTP 503。

# 接口协议文档：AmpMySQL RPC（JSON-RPC 2.0 over TCP）

> 版本：v1.0 ｜ 状态：阶段 0 交付物

## 1. 传输层

| 项目 | 约定 |
| ---- | ---- |
| 传输 | TCP（内网），默认监听 `0.0.0.0:9501` |
| 编码 | UTF-8 JSON |
| 分包 | 换行符 `\n` 分隔，一行一个 JSON-RPC 报文（与 workerman/jsonrpc 兼容） |
| 报文上限 | 单行最大 1 MiB，超出直接断开连接 |
| 并发 | 同一连接上多个请求可并发下发，响应可乱序返回，客户端按 `id` 匹配 |

## 2. 方法列表

| method | 用途 | 入参 | 出参 | 是否可重试 |
| ---- | ---- | ---- | ---- | ---- |
| `Mysql.query` | 只读查询（SELECT） | `sql`, `bindings` | `rows`, `cost_ms` | 瞬态连接错误可重试 1 次 |
| `Mysql.execute` | 写入/更新/删除 | `sql`, `bindings` | `affected_rows`, `last_insert_id`, `cost_ms` | 禁止重试 |
| `Mysql.ping` | 健康检查 | 无 | `pong`, `mysql` | 可重试 |

## 3. 请求报文

```json
{
  "jsonrpc": "2.0",
  "id": "req-123456",
  "method": "Mysql.query",
  "params": {
    "sql": "SELECT * FROM user WHERE id=?",
    "bindings": [1]
  }
}
```

字段约束：

- `jsonrpc`：必须为字符串 `"2.0"`；
- `id`：字符串或整数，必填（本服务不主动推送通知）；
- `method`：必须命中白名单，否则返回 `-32601`；
- `params.sql`：预编译 SQL（含 `?` 占位符），必填，最大长度 64 KiB；
- `params.bindings`：数组，可选，元素仅允许标量/null，长度必须与占位符一致（由 MySQL 驱动校验）。

## 4. 成功响应

`Mysql.query`：

```json
{
  "jsonrpc": "2.0",
  "id": "req-123456",
  "result": {
    "rows": [{"id": 1, "name": "demo"}],
    "cost_ms": 3
  }
}
```

`Mysql.execute`：

```json
{
  "jsonrpc": "2.0",
  "id": "req-123457",
  "result": {
    "affected_rows": 1,
    "last_insert_id": 5,
    "cost_ms": 3
  }
}
```

## 5. 错误响应

```json
{
  "jsonrpc": "2.0",
  "id": "req-123456",
  "error": {
    "code": -32000,
    "message": "SQL execution failed",
    "data": {
      "request_id": "req-123456",
      "cost_ms": 2,
      "detail": "Unknown column 'id2' in 'where clause'"
    }
  }
}
```

### 错误码规范

| code | 含义 | 客户端建议处理 |
| ---- | ---- | ---- |
| -32700 | 报文解析失败（非法 JSON） | 记录并排查发包逻辑 |
| -32600 | 无效请求（缺字段/字段非法） | 记录并排查 |
| -32601 | 方法不存在 | 排查 method 拼写 |
| -32602 | 参数错误（缺 sql / bindings 非数组等） | 排查入参 |
| -32000 | MySQL 执行错误（语法/约束等业务性失败） | 按业务处理，不重试 |
| -32001 | SQL 执行超时（默认 2s） | 只读可考虑降级 |
| -32002 | 服务过载（并发 SQL 超限，排队超时） | 熔断/降载 |
| -32003 | MySQL 连接失败（重试后仍不可用） | 返回服务不可用，触发告警 |
| -32603 | 服务内部错误（未预期异常） | 记录 + 告警 |

## 6. 超时约定

| 层级 | 超时 | 行为 |
| ---- | ---- | ---- |
| Webman RPC 总超时 | 3s | 客户端触发失败回调，返回 HTTP 504 |
| Amp SQL 执行超时 | 2s（可配） | 返回 -32001，连接归还后由连接池校验状态 |
| 报文读取 | 单行 1 MiB 上限 | 断开连接 |

## 7. 重试与幂等

- 只读 `Mysql.query`：仅当发生**瞬态连接错误**（连接断开、连接建立失败）时由 Amp 侧重试 1 次；SQL 语义错误、超时不重试；
- 写操作 `Mysql.execute`：任何情况不重试；
- 写操作幂等由网关侧 request-id + 业务唯一键保证，RPC 层不缓存去重（二期考虑）。
